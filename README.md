# Shuting Pang Homepage

A lightweight academic homepage inspired by the structure of Zhiyuan Wang's homepage.

## Files
- `index.html` — main page
- `style.css` — styling
- `script.js` — lightweight navigation behavior
- `assets/profile.*` — profile photo extracted from the CV
- `assets/Shuting_Pang_CV.docx` — downloadable CV

## Deploy on GitHub Pages
1. Create a GitHub repository, e.g. `yourusername.github.io`.
2. Upload all files in this folder to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Your page will be available at `https://yourusername.github.io/`.
